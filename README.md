# 📈 Stock Portfolio Tracker

A simple command-line **Stock Portfolio Tracker** built with Python.

This project allows users to select stocks from a predefined list, enter the quantity they own, and calculate their total investment. It is designed as a beginner-friendly Python project for practicing dictionaries, loops, user input, conditionals, and basic calculations.

## 🚀 Features

- Displays a list of available stocks and their prices.
- Allows users to enter a stock symbol.
- Accepts the quantity of shares purchased.
- Calculates the investment value for each stock.
- Keeps track of the total investment.
- Allows multiple stocks to be added to the portfolio.
- Uses `done` to finish entering stocks.
